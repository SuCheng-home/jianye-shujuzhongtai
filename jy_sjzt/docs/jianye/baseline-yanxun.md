### 7.1 暴露的全局变量（4 个，均为 `var` 全局，无模块导出）
- [ ] 7.1.1 `YX_DICT`：字典对象 `{seg[], subj[], lv[][3], cre[]}`。`seg`=6 学段名；`subj`=学科名（HTML 内联 56 项 / js 文件 55 项）；`lv`=级别三元组 `[全称, 表内短名, 归并大类]`（HTML 7 项 / js 5 项）；`cre`=组织教研员姓名（HTML 47 人 / js 36 人）。
- [ ] 7.1.2 `YX_SRC`：`{学期键: 源 xls 文件名}`，溯源用（如「研训活动统计(本区) (3).xls」）。
- [ ] 7.1.3 `YX_META`：教师基数。**两版结构不同**——js 文件为扁平 `{teacherTotal, segTeacher{学段:人数}, part{学期键:估算参与数}}` 且注释明言「估算占位（源表算不出真实去重人数），待替换」；HTML 内联为 `{teacherTotal, terms{学期:{total, seg{学段:人数}, part}}}`（13 学期，total/seg 取自《各年度骨干教师考核数据列表》名册，part 仍为估算）。
- [ ] 7.1.4 `YX_DATA`：`{学期键: 活动行数组}`。**学期键两版不一致**：js 文件用 `'1'/'2'/'3'`（仅 3 学期），HTML 内联用 `'2020-2021-1'…'2026-2027-1'`（13 学期）→ js 文件无法被 HTML 直接消费。

### 7.2 活动行字段（位置数组，10 元素；运行时追加第 11 个）
| 下标 | 字段 | 推断含义 | 粒度 |
|---|---|---|---|
| r[0] | date | 活动日期 YYYY-MM-DD | 活动级 |
| r[1] | name | 活动名称 | 活动级 |
| r[2] | seg[] | 学段下标数组（可多个） | 活动级 |
| r[3] | subj[] | 学科下标数组（可多个，可空） | 活动级 |
| r[4] | lv | 级别下标 | 活动级 |
| r[5] | cre | 组织教研员下标 | 活动级 |
| r[6] | hours | 学时 | 活动级 |
| r[7] | ying | 应参加人数（**出勤率分母**） | 活动级 |
| r[8] | absent | 未出勤人数 | 活动级 |
| r[9] | chu | 已出勤人数（**出勤率分子**） | 活动级 |
| r[10] | wk（运行时写入） | 教学周序号（0 预备周 / 负 假期） | 活动级 |

- [ ] 7.2.1 恒等式验收：每行 `r[7] === r[8] + r[9]`（13 学期全量校验通过）；出勤率 = `r[9]/r[7]`；KPI 平均出勤率 = `Σr[9] / Σr[7]`（**不是**各行出勤率的平均）。
- [ ] 7.2.2 总学时 = `Σr[6]`；组织教研员 = `distinct(r[5])` 计数；应参加人次 = `Σr[7]`；研训活动数 = 行数。
- [ ] 7.2.3 **教师参与率分子/分母**：分子 = `YX_META…part`（估算去重参与教师数），分母 = `YX_META…total`（名册教师总数，兜底 5200）；**不是**由活动行算出。
- [ ] 7.2.4 **去重参训教师数、应参训基数**：去重数原数据**不存在**（只有估算 part）；应参训基数 = 学期名册 total / 学段 seg 拆分， likewise 无教师级明细。
- [ ] 7.2.5 仅 HTML 内联、js 文件缺失的契约块：`SEM_NAME`（学期键→中文名）、`PREV`（上学期映射）、`TERM_START`（开学周一，校历锚点），分别由 `__YX_TERMS_BEGIN/END__`、`__YX_TERMSTART_BEGIN/END__` 标记包裹。**建邺版若只搬 js 文件会缺这三块，周次统计与对比行直接失效。**

### 7.3 原数据里根本不存在、建邺必须补的字段
- [ ] 7.3.1 教师级参训/出勤名单（每教师×每活动的签到记录）——不存在；现只有活动级聚合的应到/未出勤/已出勤。

- [ ] 9.1 **导出脚本断链**：`jy_sjzt/scripts/build-yanxun-html.mjs` 第 8 行读取 `../教师发展大屏/yanxun.html`，而仓库根下**只有 `教师视导/`，`教师发展大屏/` 目录不存在** → `npm run build:yanxun` 现在必然 ENOENT。脚本还校验 `<title>玄武区研训活动分析看板</title>` 与"无跨页切换标记"，并从源同目录读 `title-bg.svg`。
