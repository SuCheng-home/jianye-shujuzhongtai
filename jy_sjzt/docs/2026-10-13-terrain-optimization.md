# 数智中枢地形与学校标识优化

日期：2026-10-13

本次范围：科技地形、画布显示清晰度、学校标识。未找到项目已有的 PRD 或 .prd 文档，使用本文件记录修改与完成状态。

## 功能状态

- 科技地形：已完成。移除装饰山脉贴图，两种模式共用现有 DEM、网格和区界掩膜。科技蓝采用蓝色材质、网格和等高线，玄武湖边界保留；学校点位、大脑底座和汇聚光流同步使用高程，切换模式不改变位置。高程采样改为双线性插值。
- 画布分辨率适配：已完成。ScreenFit 将整屏缩放倍率传给地图，绘制分辨率补偿实际显示倍率。设备密度最高取 1.5，绘制像素总量最高 3,200,000，DPR 最高 2.5；保留 30fps 限帧和切离中枢暂停渲染。同比例窗口缩放也会更新绘制分辨率。
- 学校标识优化：已完成。11 张有较高清原图的标识升级至最高 256px（海英小学为 254px），39 张低清素材保留现有 160px 版本。导入脚本支持 --upgrade-only，使用项目相对目录，避免按新上限放大小原图。点位去除默认半透明，悬停与选中卡片增加 56px 标识预览。未配置校徽显示“校徽未提供”，预览加载失败显示“校徽加载失败”。
- 低清校徽源图补齐：未完成，需后续提供更清晰的原图，本次没有生成或伪造学校校徽。
- 更高清卫星影像：暂缓，本次保留原有 2048×1774 影像，调整材质降低蓝色染色和泛白。
- 原始高程数据精度审定：未开展。本次复用项目已有高程与投影，不引入新的地理数据，也不声称进行了测绘级校验。

## 性能与交付

- 科技网格与等高线在现有地形材质中计算，不新增网格图层；两种模式复用地形几何，切换时清理旧材质。
- 不再加载 map-terrain.png，也不再将这张装饰贴图内联到单文件 HTML。原素材文件保留。
- 未新增付费地图服务、在线高程接口或模拟业务数据。
- 已更新 out 静态页面与 dist/玄武区教育数智中枢.html，单文件约 21.0 MiB。

## 验证

- 独立 TypeScript 检查：通过（tsc --noEmit --incremental false；构建配置会跳过类型检查，因此另行执行）。
- 生产构建与单文件打包：通过。
- 1920×1080、设备密度 1：画布从约 1387×707 提升至 1920×978。
- 同比例缩放至 3840×2160：实际画布 2505×1277，3,198,885 像素；缩回 1080p 恢复 1920×978。
- 1920×1080、设备密度 2：实际画布 2505×1277，同样受预算限制。
- 1366×768、设备密度 2：实际画布 2048×1044，2,138,112 像素。
- 连续切换两种模式、校徽悬停预览、缺失校徽提示：通过。最终静态页面与单文件 HTML 验证中未记录到页面或控制台错误。
- 静态页面资源检查：未请求旧的装饰地形图。
- 校徽资源检查：11 张升级素材不超过原图尺寸及 256px 上限；39 张保留素材仍为 160×160。
- 本次浏览器验证使用自动化 Chromium；未进行用户实际大屏设备的 GPU 帧率、功耗或弱网加载测试。
